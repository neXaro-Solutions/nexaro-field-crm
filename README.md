# neXaro Field CRM V7

Mobile-first PWA für den Außendienst.

## Enthalten
- Start-Dashboard / KPIs
- Lead-Pipeline und Lead-Erfassung
- geführter Sales Assistant
- kundenorientierte SumUp-Empfehlung ohne interne Provision
- interne Provisions- und Deal-Kalkulation
- interne 5.000-€-Qualifizierung
- Gebietssuche per Live-Standort oder PLZ
- Radius- und Branchenfilter
- Potenzial-Scoring
- Route per Nearest-Neighbour-Heuristik
- Google-Maps-Übergabe
- Tasks / Follow-ups
- JSON-Backup und CSV-Export
- lokale Speicherung
- PWA / Service Worker

## Deployment
Für GitHub Pages: Repository als Project Page auf `main` und `/(root)` veröffentlichen.

## Daten
Die CRM-Daten liegen lokal im Browser. Es gibt bewusst kein Backend und keine offen im Repository hinterlegte API-Keys.

## Quellen / fachliche Basis
SumUp-Preise sollten vor Kundengesprächen aktuell geprüft werden.
Die interne Provisionslogik basiert auf dem hinterlegten Commission Scheme; Vertragsbedingungen gehen immer vor.
